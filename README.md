# Пользовательский сценарий

### Регистрация и вход

При первом использовании приложения пользователь может зарегистрироваться, указав имя и пароль.

Зарегистрированный пользователь может войти в приложение под своей учётной записью.

### Главная страница

На главной странице отображаются два блока:

**Ближайшие события** — три ближайших события, в которых пользователь пока не участвует;
**Мои события** — три ближайших события, к которым пользователь присоединился.

В верхней части страницы расположена навигация:

**Все события**;
**Мои события**;
**Создать событие**.

### Все события

Раздел «Все события» открывает страницу со списком доступных событий.

Пользователь может:

просматривать информацию о событиях;
фильтровать события по названию;
фильтровать события по дате;
открыть страницу конкретного события;
присоединиться к событию, если в нём есть свободные места.

### Страница события

На странице конкретного события отображается:

название;
описание;
дата и место проведения;
количество занятых и свободных мест;
список участников;
создатель события.

Если количество участников достигло установленного ограничения, новые пользователи не могут присоединиться к событию.

Для участников события доступна кнопка перехода в чат.

### Мои события

Раздел «Мои события» содержит события, к которым присоединился пользователь.

Пользователь может:

просматривать предстоящие события;
просматривать архивные события;
открыть страницу события;
перейти в чат события;
отказаться от участия в событии.

После завершения события пользователь может отметить факт своего посещения.

### Чат события

Для каждого события существует отдельный чат.

В чате могут общаться только пользователи, которые являются участниками соответствующего события.

Пользователь может:

просматривать сообщения других участников;
отправлять собственные сообщения.

### Создание события

Раздел «Создать событие» открывает страницу создания нового события.

Любой зарегистрированный пользователь может создать событие, указав необходимые данные:

название;
описание;
дату;
место проведения;
максимальное количество участников;
изображение события (при необходимости).

Пользователь, создавший событие, становится его участником.

### Основной сценарий использования

Типичный сценарий работы с приложением выглядит следующим образом:

**Регистрация → просмотр событий → выбор события → присоединение → общение в чате → посещение события → отметка о посещении.**
