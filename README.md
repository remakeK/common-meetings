Поход на события вместе: список событий, группы «идём вместе», чат, ограничение мест, отметка посещения.

#Пользовательский сценарий
Регистрация
На главное странице в левой части выведено три ближайших события, в правой части выведено три ближайших события, на которые пользователь собирается прийти
Сверху набор кнопок: все события, мои события, создать событие

Все события открывает новую страницу где выводятся все события с возможностью отфильтровать по названию, дате
Мои события открывает новую страницу где выводятся события на которые был подписан пользователь с той разницей, что здесь еще можно вывести нажатием кнопки архивные события, а также открывается доступ к чату
Чат это отдельная страница, в которой пользователи могут общаться, но только те, которые подписаны на событие. 
Создать событие открывает страницу с созданием события, где любой пользователь может создать свое событие и задать для него все необходимые данные(ограничение мест, дата, название, описание, может быть картинка)
